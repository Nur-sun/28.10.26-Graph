# Зертханалық жұмыс №3 — Ақылды қала

## Мүмкіндіктер
- 15 бастапқы төбе және 30 бағытталмаған қабырға
- Дейкстра алгоритмі `heapq` арқылы өз қолымен іске асырылған
- Қашықтық және уақыт режимдері
- Ең қысқа маршрут, жалпы салмақ, қаралған төбелер реті/саны және орындау уақыты
- NetworkX + Matplotlib визуализациясы, маршрут қызыл түспен белгіленеді
- Төбе/қабырға қосу-жою, салмақ өзгерту, жолды жабу/ашу
- JSON сақтау және қайта жүктеу
- Қате енгізулерді өңдеу

## Орнату
Python 3.10 немесе одан жаңасын орнатыңыз. Терминалда жоба бумасына өтіп:
```bash
pip install -r requirements.txt
python main.py
```

## Файлдар
- `main.py` — консольдік мәзір
- `graph.py` — граф деректері мен JSON операциялары
- `dijkstra.py` — Дейкстра алгоритмі
- `visualization.py` — графты салу
- `data/city_graph.json` — бастапқы граф
- `tests.py` — автоматты тесттер

## Ескерту
Граф бағытталмаған: қала жолымен екі бағытта жүруге болады деп модельденген. Барлық салмақтар теріс емес. Қашықтық пен уақыттың мәндері оқу жобасына арналған шартты бірліктер.
